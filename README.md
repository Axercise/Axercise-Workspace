# Axercise Workspace

พื้นที่ทำงานส่วนตัวบน Windows: Next.js + Hermes Agent พร้อมแชทแนบภาพ, Calendar, Eisenhower Tasks, Brain Dump และคลังการเรียน

## การพัฒนาและ Git

`main` เป็นเวอร์ชันที่เจ้าของยอมรับแล้ว งานแก้ไขครั้งถัดไปทำและ push บน `test` ก่อน รอเจ้าของยืนยันว่าผ่านและอนุมัติ merge จึงนำเข้า `main` ตาม [แนวทางพัฒนา](CONTRIBUTING.md)

Repo เก็บเฉพาะ source และเอกสาร ข้อมูลบัญชี, Token, ความจำ/Session ของ Hermes, ไฟล์เรียน และข้อมูลส่วนตัวใน `.axercise/` อยู่บนเครื่องและถูกกันออกด้วย `.gitignore` การ clone ไปเครื่องอื่นจึงต้องตั้งค่าบัญชีของเครื่องนั้นใหม่

## เปิดใช้งาน

ต้องมี Node.js 22.13 ขึ้นไป และ Hermes Agent ที่ติดตั้งอยู่ในเครื่อง

เปิด terminal ในโฟลเดอร์นี้ แล้วติดตั้งคำสั่งครั้งแรก:

```powershell
npm ci
npm run setup:learning
npm run build
npm link
axercise
```

สำหรับเครื่องที่พัฒนาโปรเจกต์นี้ มี dependencies และ production build เตรียมไว้แล้ว ใช้ `npm link` ครั้งเดียว จากนั้นใช้ `axercise` ได้จาก terminal ทั่วไป

หากยังไม่ได้ติดตั้งคำสั่ง ใช้จากโฟลเดอร์โปรเจกต์ได้ทันที:

```powershell
npm run axercise
```

เว็บเปิดที่ **http://127.0.0.1:3210** ระบบรันบน loopback ของเครื่องนี้

```powershell
axercise status
axercise stop
axercise restart
```

ปิดแท็บ browser ได้ เว็บ บอท และการแจ้งเตือนยังทำงานจนสั่ง `axercise stop` ระบบทำงานเมื่อคอมพิวเตอร์เปิดอยู่และบริการที่เชื่อมต่อเข้าถึงอินเทอร์เน็ตได้

## เมนูระบบและการนำทาง

กดปุ่ม **☰ เมนูระบบ** ด้านซ้ายล่างเพื่อเลือก Workspace, Daily Briefing, การเรียน หรือคลังบันทึก เมนูระบุหน้าปัจจุบันและจำนวนสรุปที่ยังไม่อ่าน พร้อมทางลัด Brain Dump, To-do / Eisenhower, ปฏิทิน และตั้งค่า บนจอเล็กปุ่มเมนูจะอยู่ในส่วนหัวของแต่ละหน้า

หน้า Learning, Library และ Daily Briefing มีปุ่ม **กลับ Workspace** เหนือชื่อหน้า ส่วนภายในรายวิชามีปุ่มกลับรายการเดิม ปุ่มหลักใช้พื้นขาว ปุ่มรองใช้เทาเข้มมีขอบ และเน้นสถานะที่เลือกเพื่อให้แยกจากข้อมูลที่แสดงได้ง่ายขึ้น เมนูใช้คีย์ลูกศรเลือก, Enter เปิด, Escape ปิด หรือกดนอกเมนูเพื่อปิดได้

## Daily Briefing

เปิดเมนู **Daily Briefing** หรือ `http://127.0.0.1:3210/briefing` เพื่อดูภาพรวมประจำวันและประวัติย้อนหลัง

- รอบเช้าเริ่มต้น **08:00**: ตารางวันนี้ งานสำคัญ 3 อันดับ งานค้าง การบ้านที่ทำเสร็จแล้วแต่ยังรอส่ง สอบ/ประเมินใน 7 วัน และชุดทบทวน
- รอบก่อนนอนเริ่มต้น **21:00**: ความคืบหน้าที่มีประวัติบันทึกวันนี้ พร้อมตารางและสิ่งที่ควรเตรียมสำหรับพรุ่งนี้
- ปรับเวลาและเปิด–ปิดแต่ละรอบ, Windows notification และ Secretary ในห้อง Discord แจ้งเตือนเดิมได้แยกกัน ทุกเวลาใช้ Asia/Bangkok
- ปุ่มสร้างสรุปตอนนี้เก็บรายงานให้อ่านในเว็บก่อน หากต้องการส่ง Discord ให้กดส่งในรายงาน สรุปอัตโนมัติจะส่งตามช่องทางที่เปิดไว้
- สรุปจากข้อมูลจริงโดยไม่เรียกโมเดล AI เพิ่ม ไม่แก้สถานะงาน/การบ้าน และรวมรายการที่ลิงก์การบ้าน–To-do–Calendar ให้ไม่ซ้ำ หากอ่านบริการไม่ได้จะแสดงแหล่งข้อมูลเก่าหรือส่วนที่ขาดพร้อมเวลา
- รายงานเก็บบนเครื่องสูงสุด 60 วัน / 180 ฉบับ ประวัติความคืบหน้า To-do เริ่มนับเมื่อเปิดใช้ฟีเจอร์; Done เดิมไม่นับว่าเพิ่งทำเสร็จวันนี้ การเปลี่ยนใน Notion ที่ตรวจพบภายหลังจะระบุว่าไม่ทราบเวลาทำเสร็จจริง
- ต้องเปิดคอมและ Axercise ไว้ ปิดแท็บเว็บได้ หากกลับมาเปิดช้าจะตามส่งเฉพาะรอบที่ผ่านไปไม่เกิน 2 ชั่วโมง ไม่ส่งรายงานเก่าสะสม และส่งอัตโนมัติไม่เกินหนึ่งครั้งต่อรอบต่อวัน
- Hermes ทั้งสามมี MCP `briefings_list/read/generate/settings` สำหรับอ่าน สร้างสรุป และเปลี่ยนเวลาตามคำขอ โดยใช้รายงานและการตั้งค่าร่วมกัน

## คลังบันทึก

เปิด **คลังบันทึก** จากเมนูซ้าย หรือ `/library` เพื่อเก็บลิงก์ ข้อความ รูปภาพ เอกสาร เสียง วิดีโอ และไฟล์ชนิดอื่น ๆ ไว้ด้วยกัน เพิ่มชื่อ แท็ก และรายการโปรดเพื่อค้นหากลับมาใช้ได้จากชื่อ ข้อความ URL หรือชื่อไฟล์

- กดเพิ่มบันทึก วางรูปจากคลิปบอร์ด ลากไฟล์มาวาง หรือเลือกอัปโหลดได้ สูงสุด 20 ไฟล์ต่อบันทึก ไฟล์ละ 50 MB ไฟล์ต้นฉบับอยู่บนเครื่องและเปิดกลับได้โดยไม่ต้องเชื่อม Notion
- ดูภาพ/PDF และเล่นเสียง/วิดีโอที่เบราว์เซอร์รองรับได้ในคลัง ไฟล์ชนิดอื่นดาวน์โหลดต้นฉบับกลับไปเปิดด้วยโปรแกรมบนเครื่องได้ ลิงก์เก็บเป็น bookmark ไม่ใช่สำเนาเว็บไซต์แบบ offline
- ในแชทแนบภาพหรือไฟล์แล้วสั่ง เช่น “เก็บรูปนี้พร้อมลิงก์ https://example.com ไว้ในคลังบันทึก แท็กไอเดีย” AI จะใช้ `library_save` เก็บไฟล์จริง ไม่ใช่แค่คำบรรยายรูป แชทแนบภาพได้ 2 ภาพ ภาพละ 4 MB และไฟล์อื่น 12 ไฟล์ ไฟล์ละ 50 MB
- Hermes, Secretary และ Developer ใช้คลังบันทึกเดียวกัน และค้นหาของที่เก็บแล้วผ่าน `library_list`/`library_read` ได้ ไฟล์แนบ Discord ที่ Hermes ดาวน์โหลดมาแล้วนำเข้าจาก cache ของ Agent นั้นเป็นสำเนาถาวรในคลังได้
- แก้ไข ย้ายลงถังขยะ กู้คืน และลบถาวรได้ ไฟล์ที่ใช้ร่วมกับบันทึกอื่นจะยังเก็บไว้ การแก้ไขตรวจ revision เพื่อไม่ทับการเปลี่ยนแปลงใหม่ และคำขอบันทึกที่ส่งซ้ำใช้ capture key เดิมป้องกันรายการซ้ำ
- ข้อความฉบับร่างอยู่ในเบราว์เซอร์ ไฟล์ที่แนบแต่ยังไม่ได้กดบันทึกจะรอไว้ไม่เกิน 7 วัน ไฟล์ที่บันทึกเข้าคลังแล้วเก็บไว้จนผู้ใช้ลบถาวร

ข้อมูลและไฟล์อยู่ใน `.axercise/library/` ซึ่งถูกกันออกจาก Git เช่นเดียวกับข้อมูลส่วนตัวอื่น ๆ คลังนี้แยกจาก Brain Dump เดิมที่เชื่อม Notion

## ศูนย์สถานะระบบ

กดไอคอน **ชีพจร / ศูนย์สถานะระบบ** ข้างกระดิ่งได้จากทุกหน้า เพื่อตรวจ AI ทั้งสามโปรไฟล์, Notion, Google Calendar และ Discord ทั้งสามบอท มีผลตรวจล่าสุด สาเหตุที่ต้องดูแล ประวัติปัญหา/กลับมาเชื่อมได้ และปุ่มตรวจซ้ำหรือเปิดการตั้งค่าที่เกี่ยวข้อง

- ตรวจอัตโนมัติประมาณทุก 2 นาทีขณะ Axercise ทำงาน แม้ปิดแท็บเว็บ การตรวจ AI อ่านบัญชีและรายการโมเดล ไม่ส่งข้อความเข้าโมเดลหรือเพิ่ม Session ทดสอบ
- ตรวจ Notion Token และสิทธิ์ฐานข้อมูล Tasks/Brain Dump/การเรียน, ตรวจการอ่าน Calendar ที่เลือกและต่ออายุ access token, ตรวจ Bot Token/intent/เซิร์ฟเวอร์พร้อม Gateway จริง รวมสิทธิ์ห้องแจ้งเตือนของ Secretary
- หาก Gateway มีปัญหา กดเริ่มการเชื่อมต่อใหม่เฉพาะ Agent นั้นได้ ระบบไม่เริ่มใหม่ขณะตรวจพบงานแชต/งานมอบหมายค้างอยู่ บัญชี AI ที่ต้องล็อกอินมีคำสั่งเชื่อมเฉพาะโปรไฟล์ให้คัดลอก ส่วน Google เปิด OAuth และ Notion/Discord เปิดหน้าตั้งค่าที่ตรงกัน
- แจ้งปัญหาที่พบต่อเนื่องและแจ้งเมื่อกลับมาพร้อมผ่าน Windows/Discord โดยรวมเหตุที่พบพร้อมกันเป็นข้อความเดียว ไม่ส่งซ้ำทุกครั้งที่ตรวจ และไม่ส่งข้อความขัดข้องเก่าที่ค้างอยู่เมื่อบริการนั้นกลับมาแล้ว เปิด–ปิดแต่ละช่องทางได้ในศูนย์สถานะ
- OpenRouter ที่ยังไม่มี Key แสดงว่ายังไม่ตั้งค่าแยกจากบริการขัดข้อง ผลตรวจบัญชี AI เป็นการตรวจความพร้อมของการเชื่อมต่อ ไม่ใช่การทดสอบคำตอบหรือรับรองโควตาทุกโมเดล

ข้อมูลประวัติและคิวแจ้งสถานะอยู่ใน .axercise/health.json ค่า Token และข้อมูลบัญชีไม่ถูกส่งกลับในผลตรวจสาธารณะ การแก้สิทธิ์หรือการล็อกอินที่ต้องยืนยันบัญชียังคงทำผ่านหน้าของบริการนั้น

## เปิดพร้อม Windows

เครื่องนี้เปิดใช้แล้ว: Axercise จะเริ่มเว็บ บอท และการแจ้งเตือนเบื้องหลังหลังล็อกอินบัญชี Windows โดยไม่เปิดเว็บหรือหน้าต่าง CMD ขึ้นมาเอง เปิดหน้าเว็บเมื่อพร้อมด้วยคำสั่ง `axercise`

ปรับได้ที่ **ตั้งค่า → Workspace → เปิดพร้อม Windows** ตัวเลือกนี้บันทึกทันที หรือใช้คำสั่ง:

```powershell
axercise startup status
axercise startup on
axercise startup off
```

`axercise stop` หยุดบริการรอบปัจจุบัน โดยยังคงตั้งให้เปิดหลังล็อกอินครั้งถัดไป ส่วน `axercise startup off` ยกเลิกการเปิดครั้งถัดไปโดยไม่หยุดงานที่กำลังทำอยู่ เมื่อย้ายโฟลเดอร์โปรเจกต์หรือเปลี่ยนตำแหน่ง Node.js ให้เปิดใช้ตัวเลือกนี้อีกครั้งจากตำแหน่งใหม่

ใช้ shortcut ของบัญชีผู้ใช้ในโฟลเดอร์ Startup ตาม [แนวทางของ Microsoft](https://support.microsoft.com/en-us/windows/experience/startup-boot/configure-startup-applications-in-windows) ตัว launcher ใช้โปรแกรม Node.js ด้วยพาธเต็มและมีบันทึกผลใน `.axercise/startup.log` หาก Windows ปิดรายการนี้ใน Settings → Apps → Startup หน้า Axercise จะแสดงสถานะให้ตรวจเปิดรายการนั้น

## Agent ชุดใหม่

| Agent | หน้าที่ |
| --- | --- |
| Hermes | ผู้ช่วยหลัก วางแผนและมอบหมายงานให้ผู้ช่วยจริงผ่านเครื่องมือ |
| Secretary | ตารางเรียน นัดหมาย งาน ไอเดีย และการแจ้งเตือน |
| Developer | เขียน ตรวจสอบ และแก้ไขโค้ดบนเครื่อง |

แต่ละตัวใช้ `HERMES_HOME` ใหม่แยกกันภายใต้ `.axercise/hermes/` จึงแยกความจำและ Session ของ Axercise จากบอทชุดเก่า

เครื่องมือของ Agent ทำงานได้ภายใต้สิทธิ์บัญชี Windows ตามที่ผู้ใช้เลือก โปรแกรม Hermes ยังบังคับกฎภายในของตัวโปรแกรมเองด้วย

## เชื่อม AI

### OpenRouter

เปิด **ตั้งค่าและการเชื่อมต่อ → AI** ใส่ OpenRouter API Key และบันทึก ค่าเริ่มต้น `openrouter/free` เป็น free-model router ของ OpenRouter สามารถเลือกหรือใส่ model ID อื่นในหน้าแชทได้ โมเดลแต่ละตัวรองรับภาพและเครื่องมือต่างกัน และใช้โควตาของบัญชีผู้ให้บริการ

### บัญชี ChatGPT / Codex

```powershell
axercise login
```

โปรแกรมจะเปิดตัวเลือกโมเดลของ Hermes ทีละ Agent ให้เลือก **ChatGPT or Codex Subscription** และทำขั้นตอนล็อกอินของ Hermes จากนั้นเลือกโมเดลที่บัญชีใช้ได้ โปรแกรมเก็บค่า provider/model ที่เลือกกลับมาเป็นค่าเริ่มต้น

ล็อกอินเฉพาะตัวได้ด้วย `axercise login hermes`, `axercise login secretary` หรือ `axercise login developer` ถ้าระบบทำงานอยู่ คำสั่ง login จะหยุดระบบก่อนเพื่อหลีกเลี่ยงการเปลี่ยน credential พร้อมกับ gateway ที่กำลังทำงาน ล็อกอินเสร็จแล้วเปิด `axercise` อีกครั้ง

กรณีย้ายที่ติดตั้ง Hermes ให้ตั้ง `AXERCISE_HERMES_PATH` เป็นโฟลเดอร์ `hermes-agent` ซึ่งมี `venv/Scripts/python.exe`

## เชื่อม Notion ชุดใหม่

1. สร้าง Internal Integration ที่ [Notion Integrations](https://www.notion.so/profile/integrations) โดยเปิดสิทธิ์อ่าน เพิ่ม และแก้ไขเนื้อหา
2. สร้างหน้า Notion ใหม่ เช่น **Axercise** แล้วเพิ่ม Integration ใน Connections ของหน้านั้น
3. เปิด **ตั้งค่า → Notion** ใส่ Integration Token กับลิงก์หน้าที่สร้าง แล้วบันทึก
4. กด **สร้างฐานข้อมูลใหม่** ระบบจะสร้าง **Axercise · Tasks** และ **Axercise · Brain Dump** และจดจำ ID เพื่อไม่สร้างซ้ำเมื่อกดอีก

Tasks เก็บ Name, Details, Deadline, Important, Urgent และ Status ส่วน Brain Dump เก็บ Name, Content และ Tags

การแก้ผ่านหน้าเว็บและผ่าน AI ใช้ connector เดียวกัน โดย AI เข้าถึงผ่าน MCP tools ของ Axercise หน้าเว็บดึงข้อมูลหลังแก้ไข หลังจบการตอบ และทุก 30 วินาทีเมื่อเปิดใช้งาน รวมถึงเมื่อกลับมาโฟกัสหน้าต่าง

## เชื่อม Google Calendar

## ศูนย์แจ้งเตือน

กดปุ่มกระดิ่งมุมขวาล่างได้จากทุกหน้า เพื่อดูรายการถึงเวลา กำหนดการทั้งหมด และประวัติที่รับทราบแล้ว เปิด–ปิด Windows/Discord/เสียง และเลือกเตือนซ้ำทุก 1, 5, 10, 15, 30 หรือ 60 นาทีได้ ค่าเริ่มต้น 10 นาที

- ครอบคลุม Google Calendar, To-do ใน Notion, การบ้าน, วันสอบ/ประเมิน, ช่วงอ่านในแผน, รอบทบทวน Flashcards, รอบจับเวลาอ่าน และฉบับร่างงานที่มีกำหนดส่ง รายการไม่มีวันที่ไม่สร้างเตือน; Brain Dump ที่ไม่มีวันนัดหมายเป็นบันทึกตามเดิม
- เตือนก่อน 30 / 15 / 5 นาที เมื่อถึงเวลา และเตือนซ้ำจนกดรับทราบ ส่วนรอบจับเวลาอ่านเตือนเมื่อครบรอบเท่านั้น งานแบบวันที่อย่างเดียวใช้ 23:59 ของวันนั้น; วันสอบและ Calendar ทั้งวันใช้ 09:00 เขตเวลา Bangkok
- Windows ใช้การแจ้งเตือนของแอป Axercise โดยตรง พร้อมรับทราบ / เลื่อน 10 นาที / เปิดดู ปิดแท็บเว็บได้ขณะบริการยังรัน เบราว์เซอร์เป็นช่องทางสำรองเมื่อ native ใช้ไม่ได้และผู้ใช้อนุญาตแจ้งเตือนแล้ว
- Secretary ส่งเข้าห้อง **#แจ้งเตือน** ใน Work with me พร้อม mention ผู้ใช้ กด Reaction ✅ เพื่อรับทราบ หรือ 💤 เพื่อเลื่อน 10 นาที รับคำสั่ง Reaction จากบัญชีเจ้าของที่ตั้งไว้เท่านั้น
- รับทราบหรือเลื่อนจากเว็บ Windows และ Discord ใช้สถานะเดียวกัน การรับทราบหยุดเตือน แต่ไม่เปลี่ยนงานเป็นเสร็จหรือบันทึกส่งการบ้าน เมื่องานเสร็จ/การบ้านส่งแล้ว/เก็บรายวิชาจะหยุดเตือนที่เกี่ยวข้อง การบ้านทำเสร็จแต่ยังไม่ส่งยังเตือนอยู่
- เชื่อมการบ้าน/Tasks/Calendar เป็นรายการเดียวเมื่อมี ID อ้างอิงร่วมกัน เก็บสถานะใน .axercise/reminders.json เพื่อไม่ลืมการรับทราบหลังเริ่มบริการใหม่ เปลี่ยนกำหนดการเป็นเวลาใหม่จะเริ่มการเตือนสำหรับเวลานั้น
- ตัวจัดการทำงานทุก 20 วินาทีและสแกนแหล่งข้อมูลทุก 60 วินาที เมื่อกลับจาก sleep จะส่งรอบล่าสุด การกด Reaction อาจใช้เวลาเพิ่มตามรอบตรวจและเครือข่าย ปิดเครื่อง/sleep/สั่ง **axercise stop** จะหยุดการทำงานนี้

กด **ทดสอบแจ้งเตือน** ในศูนย์แจ้งเตือนเพื่อลองส่งจริง รายการทดสอบหมดอายุใน 60 นาที Windows อาจเก็บไว้ในศูนย์แจ้งเตือนเมื่อเปิด Do not disturb หรือปิด banner ของ Axercise; แอปไม่เปลี่ยนสิทธิ์และโหมดห้ามรบกวนของ Windows ให้เอง Agent ทั้งสามมี MCP tools **reminders_list** และ **reminders_update** สำหรับดู รับทราบ เลื่อน หรือเปิดเตือนอีกครั้ง

## To-do เชื่อม Calendar

เปิดรายละเอียดงานใน To-do แล้วเลือก **แสดงงานนี้ใน Calendar** และกดบันทึก ใช้วันที่ของ To-do เดิมเพียงช่องเดียว รวมถึงงานที่เชื่อมมาจากการบ้าน ไม่ต้องเพิ่มกำหนดส่งซ้ำในรายวิชา

- วันที่อย่างเดียวแสดงเป็นงานทั้งวัน ถ้างานเดิมระบุเวลาไว้จะแสดงช่วง 30 นาทีจากเวลานั้น
- แก้ชื่อ รายละเอียด วันที่ และสถานะจาก To-do หรือ AI แล้ว Calendar จะอัปเดตรายการเดิม งาน Done มีเครื่องหมาย ✓ ใน Calendar ส่วนการกลับมาทำต่อใช้รายการเดิม
- เลือก **7 วัน** ใน Calendar เพื่อดูงานกับนัดหมายรวมกันนับจากวันที่เลือก บน Desktop แผงจะขยายให้เห็นรายการมากขึ้น และยังลากปรับความสูง/ความกว้างได้ กดรายการที่มีป้าย To-do เพื่อเปิดงานต้นทาง
- เอาเครื่องหมายแสดงใน Calendar ออกเพื่อนำเฉพาะสำเนาในปฏิทินออก งานใน Notion/การบ้านยังอยู่ ลบงานจาก To-do จะนำสำเนา Calendar ที่เชื่อมไว้ออกด้วย
- ถ้า Calendar ขัดข้อง งานยังบันทึกใน Notion พร้อมสถานะรอลองใหม่ ระบบเบื้องหลังจะลองซิงก์ให้อีกครั้ง เก็บการเชื่อมไว้ใน .axercise/task-calendar.json เพื่อใช้ต่อหลัง restart
- AI ทั้งสามใช้ tasks_create/tasks_update พร้อม calendarEnabled=true/false ได้ ถ้าไม่ระบุค่านี้จะคงการเชื่อมเดิม งานที่เชื่อมเป็นรายการเดียวในระบบแจ้งเตือนรวม

## ฉบับร่างและ Brain Dump

- กด **Brain Dump** หรือ `Ctrl+B` เพื่อเปิดแผงด้านขวา
- ข้อความที่กำลังพิมพ์เก็บเป็น draft ใน localStorage ของ browser นี้
- กด **เก็บในเครื่อง** เพื่อเก็บไอเดียเป็นรายการฉบับร่าง หรือ **ส่งเข้า Notion** เพื่อบันทึกออนไลน์
- ฟอร์มเพิ่มงานมี **เก็บฉบับร่าง** เช่นกัน เปิดส่งภายหลังใน **ดูงานทั้งหมด**
- ฉบับร่างยังไม่ถูกส่งออนไลน์จนกดส่ง และการล้างข้อมูลเว็บไซต์จะลบฉบับร่างใน browser

ใช้ URL เดิมเป็นประจำ เพราะ `127.0.0.1` และ `localhost` มีพื้นที่ localStorage คนละชุด

## การเรียน

เปิด **การเรียน** จาก sidebar หรือ [หน้าเรียนบนเครื่องนี้](http://127.0.0.1:3210/learning) แล้วสร้างเทอมและรายวิชา ข้อมูลและไฟล์เรียนบันทึกลงเครื่องทันที ใช้ต่อได้เมื่ออินเทอร์เน็ตขัดข้อง หากบริการ Axercise ยังทำงานอยู่

- รายวิชาเก็บอาจารย์ อีเมล ตารางเรียน สถานที่สอบ และกลุ่มน้ำหนักคะแนน
- เอกสารเปิด PDF/รูปภาพในเว็บได้ ไฟล์ Office แสดงข้อความที่สกัดได้และดาวน์โหลดต้นฉบับได้ เพิ่มเวอร์ชันจากปุ่มในหน้าดูไฟล์เพื่อรักษาฉบับเดิม จุดที่อ่านและคั่นหน้าแยกตามเวอร์ชัน
- ในรายวิชา → **เอกสารเรียน → เพิ่มลิงก์** เก็บลิงก์เว็บพร้อมชื่อ หมวด บท แท็ก โน้ต และปักหมุดได้ ค้นจากชื่อ/URL หรือกรองไฟล์กับลิงก์แยกกัน กดเปิดต้นทาง คัดลอก แก้ไข และลบได้ รวมถึงแนบลิงก์กับการบ้าน ลิงก์เก็บเฉพาะที่อยู่เว็บ การอ่านแบบออฟไลน์และค้นในเนื้อหาใช้ไฟล์ที่อัปโหลด
- ลิงก์เรียนรวมอยู่ใน ZIP สำรองและรายละเอียดที่ซิงก์ Notion การลบลิงก์ลบเฉพาะรายการในรายวิชา ส่วนเว็บไซต์/ไฟล์ที่ต้นทางยังอยู่ AI บันทึกด้วย `learning_save` ชนิด `documents` พร้อม `courseId`, `title`, `url` ได้
- กดรูปถังขยะบนการ์ดเอกสาร หรือ **ลบเอกสาร** ในหน้าอ่าน แล้วตรวจรายละเอียดก่อนยืนยัน จะลบไฟล์ทุกเวอร์ชันและดัชนีค้นหา การลบรายการ Notion ส่งเมื่อกดซิงก์ โน้ต/ชุดทบทวนยังเก็บไว้โดยระบุว่าเอกสารต้นทางถูกลบ
- การบ้านเก็บโจทย์ rubric, checklist, ไฟล์งาน ฉบับที่ส่ง เวลา และ feedback สถานะ **ทำเสร็จ** ยังอยู่ในงานรอส่งจนระบุ **ส่งแล้ว** งานอ่านจากแผนสอบแยกเป็นประเภททบทวน
- คะแนนว่างหมายถึงรอผล ส่วนเลขศูนย์เป็นผลคะแนนจริง เพิ่มรายการประเมินให้ครบทั้งกลุ่มก่อนใช้ตัวเลขคาดการณ์ น้ำหนักภายในกลุ่มใช้สัดส่วนของรายการที่บันทึกไว้
- **ทบทวนวิชานี้** มี AI จากเอกสาร โน้ต Flashcards/แบบทดสอบพร้อมประวัติการตอบ แผนสอบที่เปิดแก้ก่อนเก็บ และจับเวลาอ่าน/พักพร้อมจดจุดที่ทำค้างไว้
- ชุดทบทวนใส่บทและแท็กได้ รวมคำถามที่ยังจำไม่ได้/ยังยากเป็นชุดใหม่ หรือเปลี่ยน feedback เป็นงานทบทวน แผนอ่านเก็บประวัติการเปลี่ยนแปลงล่าสุด 20 ครั้ง
- โหมด **ตรวจโจทย์ / Checklist** เทียบ rubric กับข้อความจากไฟล์หมวด **ไฟล์งาน** ที่ผูกกับการบ้านนั้น แสดงพบหลักฐาน/ยังไม่ตรงเกณฑ์/ยังยืนยันไม่ได้ พร้อมข้อจำกัดของข้อความที่อ่านได้ ไม่มีการให้คะแนนอัตโนมัติ
- **ซิงก์ Notion** ส่งรายละเอียดเข้า **Axercise · Learning** ใช้บัญชี Notion เดิม กดเองเมื่อพร้อมออนไลน์ ข้อมูลที่แก้ทั้งสองฝั่งจะแสดงให้เลือกก่อนใช้ ไฟล์ต้นฉบับอยู่บนเครื่องและอยู่ใน ZIP สำรอง
- เชื่อมการบ้านกับ Tasks เป็นรายงานได้ ชื่อ/รายละเอียด/กำหนด/สถานะเชื่อมสองทาง งานที่เชื่อมแล้วส่งการแก้ไขเบื้องหลังและเก็บสถานะรอลองใหม่เมื่อเชื่อมไม่สำเร็จ กรณีแก้ทั้งสองฝั่งต้องเลือกข้อมูลก่อน
- เมื่อเพิ่มการบ้าน เลือก **แสดงการบ้านนี้ใน To-do List** และช่อง Eisenhower ได้ทั้งสี่ช่อง หรือเปิดการบ้านเดิม → เลือกช่อง → **เพิ่มเข้า To-do List** การย้ายช่องอัปเดต Task เดิม ลิงก์จาก To-do เปิดกลับรายวิชาได้ การกดงานเสร็จใน To-do หมายถึงทำเสร็จรอส่ง จนบันทึกการส่งจากหน้าการบ้าน
- AI เพิ่มการบ้านด้วย `learning_save` โดยตั้ง `taskRequested`, `taskImportant`, `taskUrgent` หรือใช้ `learning_link` พร้อม `quadrant` 0–3 ตามลำดับ ทำทันที/วางแผน/มอบหมาย/ตัดออก
- **สำรองข้อมูลทั้งหมด** หรือ **สำรองวิชานี้** สร้าง ZIP พร้อม checksum; **นำกลับจาก ZIP** แสดงตัวอย่างและรายการที่ต่างกันก่อนนำเข้า ใช้เก็บเทอมเก่าได้
- หากต้นฉบับหายหรือเนื้อหาเปลี่ยน เว็บแจ้งชื่อไฟล์และให้กู้จาก ZIP โดยแสดงรายการซ่อมก่อนนำเข้า สำเนาไฟล์เสียเก็บแยกใน `.axercise/learning/recovered-originals/`

ติดตั้งตัวอ่านข้อความครั้งแรกด้วย `npm run setup:learning` ใช้ Python/PyMuPDF แยกที่ `%LOCALAPPDATA%/Axercise/runtimes/learning-python` บน Windows หรือกำหนด `AXERCISE_LEARNING_PYTHON` เอง ข้อมูลเรียนอยู่ใน `.axercise/learning/` ให้สำรองผ่านเมนูในเว็บ

ข้อจำกัดที่แสดงในระบบ: ไฟล์ละไม่เกิน **50 MB**, PDF ไม่เกิน **500 หน้า**, ข้อความรวมไม่เกิน **2 ล้านตัวอักษร**, ZIP สำรองรวมไม่เกิน **256 MB** แบ่งสำรองรายวิชาได้ รองรับ PDF, PNG/JPG/WebP/GIF, DOCX/PPTX/XLSX, TXT/MD/CSV, ZIP และไฟล์โค้ดที่กำหนดไว้ ZIP ทั่วไปเก็บเพื่อดาวน์โหลด ไม่มีการรันไฟล์ที่อัปโหลด

AI ใช้โมเดลที่เลือกใน Workspace และอ่านข้อความที่ดึงมาสูงสุด 10 หน้า/ส่วนต่อคำขอ พร้อมแหล่งอ้างอิงไฟล์/เวอร์ชัน/หน้า ไฟล์สแกนใช้ **อ่านภาพหน้านี้ด้วย AI** ทีละหน้า ต้องมีโมเดลรองรับภาพและอินเทอร์เน็ต การสร้างชุดทบทวนเป็นคำถามพร้อมเฉลยให้ประเมินตนเอง เวลาในแผนใช้ Asia/Bangkok

ปุ่มส่งวันสอบ/ช่วงอ่านเข้า Calendar และการเตือนผ่าน Secretary ต้องเชื่อม Google/Discord ก่อน การเตือนรวมงานทำเสร็จที่ยังไม่ส่ง วันสอบ และชุดทบทวนที่ถึงรอบ แยกตามบัญชีที่ตั้งไว้บนเครื่องนี้

## การพัฒนาและตรวจสอบ

```powershell
npm run dev
npm run typecheck
npm test
npm run build
```

หยุด `axercise` ก่อนใช้ `npm run dev` เพราะใช้ port เดียวกัน

API สำหรับหน้าเว็บตรวจ Host/Origin และป้องกันคำขอเขียนข้ามเว็บไซต์ ส่วนเครื่องมือ AI และงานแจ้งเตือนใช้ service token ภายใน Credential อยู่ฝั่ง server ใน `.axercise/` ซึ่งถูก ignore จาก Git และไม่ถูกส่งกลับใน API การตั้งค่า

สถานะการตรวจสอบและข้อจำกัดอยู่ใน [docs/VERIFICATION.md](docs/VERIFICATION.md)
