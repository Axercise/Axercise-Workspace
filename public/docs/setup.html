ติดตั้ง Axercise Workspace บน Windows

แต่ละเครื่องใช้บัญชีและโปรไฟล์ของเจ้าของเครื่องเอง การ clone ครั้งแรกจะได้พื้นที่ว่างสำหรับแชท ไฟล์เรียน และคลังบันทึก

1. เปิด Workspace ครั้งแรก

ติดตั้ง Git, Node.js 22.13 ขึ้นไป และ Hermes Agent สำหรับ Windows เลือกการติดตั้งแบบ source ที่มีโฟลเดอร์ hermes_cli และ Python ใน venv/Scripts หรือ .venv/Scripts รุ่นที่ใช้ต้องมี Gateway API สำหรับ sessions และรองรับ MCP

git clone https://github.com/Axercise/Axercise-Workspace.git
cd Axercise-Workspace
npm ci
npm run build
npm link
axercise

ระหว่างที่ฟีเจอร์นี้อยู่บน branch ทดสอบ ให้ใช้ git switch test หลังเข้าโฟลเดอร์และก่อนติดตั้ง เว็บเปิดที่ 127.0.0.1:3210 ถ้า Windows ไม่พบคำสั่ง axercise ให้ใช้ npm run axercise จากโฟลเดอร์โปรเจกต์

2. เชื่อม Hermes และบัญชี AI

  1. หน้าตั้งค่าจะค้นหา Hermes ในเครื่อง ถ้าติดตั้งไว้ที่อื่นให้ใส่ตำแหน่งโฟลเดอร์ hermes-agent เลือกสิทธิ์ในการรันคำสั่ง แล้วกด ตรวจหาและเชื่อม Hermes
  2. กด เชื่อม AI แล้วเลือกหนึ่งวิธี
    • ChatGPT กด “เข้าสู่ระบบผ่าน Hermes” ในหน้าต่างที่เปิดให้เลือก ChatGPT or Codex Subscription และยืนยันในเบราว์เซอร์ ใช้บัญชีเดียวกันได้สำหรับทั้งสามโปรไฟล์ ระหว่างล็อกอิน Workspace จะหยุดชั่วคราวและเปิดอีกครั้งเมื่อเสร็จ ถ้าปิดหน้าต่างกลางคัน ให้รัน axercise login แล้ว axercise
    • OpenRouter เลือก OpenRouter ใส่ API key และชื่อโมเดลที่บัญชีใช้ได้ เช่น openrouter/free แล้วกดบันทึก

3. เชื่อม Notion แล้วเข้าใช้งาน

  1. สร้าง Notion Internal Integration ใน Workspace ของคุณ เปิดสิทธิ์อ่าน เพิ่ม และแก้ไขเนื้อหา
  2. สร้างหน้า Axercise ใน Notion เปิดเมนู ••• → Connections แล้วเพิ่ม Integration ให้กับหน้านั้น คัดลอกลิงก์หน้าด้วย Copy link
  3. กด เชื่อม Notion ใน Axercise ใส่ Integration Token และลิงก์ กดบันทึก แล้วกด สร้างฐานข้อมูลใหม่ รอ Tasks และ Brain Dump ขึ้นว่าพร้อม
  4. ปิดหน้าต่างตั้งค่า กด ตรวจการเชื่อมต่อและเข้า Workspace หาก Gateway เพิ่งเริ่ม ให้รอสักครู่แล้วลองอีกครั้ง ถ้า Notion แจ้งสิทธิ์ไม่พอให้ตรวจ Connections ของหน้าที่คัดลอกมา

ลองพิมพ์ในแชท “เพิ่มงานอ่านบทที่ 1 ไว้ใน To-do” แล้วเปิด To-do เพื่อตรวจรายการ Hermes ได้รับเครื่องมือของ Axercise ผ่าน Workspace MCP อัตโนมัติ เก็บ token ในหน้าตั้งค่าเท่านั้น

4. เพิ่มบริการเมื่อพร้อม

  • Google Calendar เปิด Google Calendar API ใน Google Cloud สร้าง OAuth Client ชนิด Web application เพิ่ม redirect URI http://127.0.0.1:3210/api/calendar/callback และเพิ่ม Test user หากอยู่ในโหมด Testing ใส่ Client ID และ Secret ที่ ตั้งค่า → Calendar กดบันทึก แล้วกดเชื่อมบัญชี Google
  • Discord สร้างบอทของตัวเองสำหรับแต่ละ Agent เปิด Message Content Intent เชิญบอทเข้าเซิร์ฟเวอร์ อนุญาตให้อ่านและส่งข้อความ ใส่ Bot token และ User ID ของเจ้าของใน ตั้งค่า → Discord ถ้าต้องการให้ Secretary เตือน ให้เพิ่ม Channel ID ของห้องและเปิดสิทธิ์ Add Reactions
  • เอกสารเรียน หลังเชื่อม Hermes รัน npm run setup:learning ในโฟลเดอร์โปรเจกต์เพื่อติดตั้งตัวอ่านข้อความ

กลับมาจัดการได้จาก ☰ → ตั้งค่า → Workspace ข้อมูลส่วนตัวอยู่ใน .axercise/ ของเครื่องที่ใช้งาน ปิดแท็บได้เมื่อใช้คำสั่ง axercise บอทและการแจ้งเตือนบนเครื่องทำงานขณะที่คอมเปิดอยู่ ใช้ axercise stop เพื่อหยุด
